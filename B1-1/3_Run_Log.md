# 실행 로그

**모델**: GPT-5.4 mini / **채널**: 웹 / **날짜**: 2026-07-11

## 1. 시나리오 설명

신규 앱 '데일리핏' 출시 관련 가상 회의록을 바탕으로, 시스템 설계 단계에서 만든 시스템 프롬프트(미노 코치 페르소나)를 GPT-5.4 mini에 적용해 12턴(사용자 6회, AI 6회)에 걸친 대화를 진행했다. 이 시나리오는 단순 1회성 요약이 아니라, 실무에서 흔히 발생하는 후속 수정 요청(리스크 강조), 뒤늦은 정보 추가(서버 부하 테스트 일정 확정), 과거 내용 재확인(디자인 담당자 기한), 중간 조건 변경(톤 변경 및 표기 방식 변경)까지 포함하도록 설계했다. 이를 통해 AI가 여러 턴에 걸쳐 회의록의 세부 정보와 이전에 확정된 규칙을 얼마나 일관되게 유지하는지 검증하는 것이 목적이다.

## 2. 12턴 대화 요약

| Turn | 발화자 | 내용 요약 |
|---|---|---|
| 1 | 사용자 | 데일리핏 회의록 원문 제공, 요약 요청 |
| 2 | AI | 결정사항/Action Items/리스크/후속 일정 형식으로 1차 요약 출력. 서버 부하 테스트 미정 사실을 리스크에 반영, 회의록 작성 담당자는 "확인 필요"로 정직하게 표시 |
| 3 | 사용자 | 서버 부하 테스트 리스크를 더 강조해서 재정리 요청 |
| 4 | AI | 리스크 항목에 하위 bullet를 추가해 "출시일 잠정안의 핵심 전제가 미확정"임을 강조하여 재정리 |
| 5 | 사용자 | **(뒤늦은 정보 제공)** 서버 부하 테스트가 7/22~7/24로 확정됐다고 통보 |
| 6 | AI | 새 일정을 결정사항·Action Items에 반영, 관련 리스크 문구는 삭제. 기존 다른 정보(출시일 잠정, 광고 예산 미정 등)는 그대로 유지 |
| 7 | 사용자 | 디자인 담당자 기한이 무엇이었는지 재질문 (문맥 기억 테스트) |
| 8 | AI | 이전 턴의 두 기한(7/10, 7/15)을 정확히 재출력 |
| 9 | 사용자 | **(조건 변경)** 톤을 단호하게, "디자인 담당자" → "디자인팀"으로 표기 변경 요청 |
| 10 | AI | 변경 규칙을 확인하고 적용 예시 제시 (전체 재정리는 보류, 예시만 제공) |
| 11 | 사용자 | 바뀐 규칙을 적용한 전체 최종본 요청 |
| 12 | AI | 톤 변경 + "팀" 표기 적용 + 서버 테스트 최신 일정 반영 + 기존 결정사항 모두 유지한 최종 요약본 출력 |

## 3. 문제 지점과 개선 요약

| 검증 항목 | 세부 내용 |
|---|---|
| 신규 정보 반영 (Turn 5→6) | 서버 부하 테스트 확정 일정(7/22~7/24)을 결정사항·Action Items에 즉시 반영하고, 관련 리스크 문구를 자연스럽게 제거함 |
| 과거 정보 기억 (Turn 7→8) | 여러 턴 전에 언급된 디자인 담당자의 두 기한(7/10, 7/15)을 누락이나 왜곡 없이 정확히 재현함 |
| 조건 변경 반영 (Turn 9→10→12) | 톤 변경과 "팀" 표기 변경 요청을 인지하고, Turn 12 최종본에서 전체 항목에 일관되게 적용함 (마케팅팀/개발팀/디자인팀) |
| 기존 내용 유지 여부 (Turn 12) | 조건 변경 이후에도 출시일(8/5 잠정), 광고 예산 미정, 회의록 작성 담당 미정 등 기존 확정 정보는 그대로 유지됨 |
| 불확실 정보 처리 | "회의록 작성 담당자"를 전 턴에 걸쳐 지어내지 않고 지속적으로 "확인 필요"로 정직하게 표시함 |
| 경미한 문제점 | Turn 10에서 사용자가 "전체 요약본"이 아닌 조건 변경만 안내했음에도, AI가 즉시 전체 재정리를 하지 않고 "적용 예시"만 제시한 뒤 "전체 다시 정리해드릴까요?"라고 되물음. 결과적으로 Turn 11에서 사용자가 재요청한 후에야 전체본이 나옴 |

**종합 판정**: 문맥 유지 Pass. 12턴에 걸쳐 이전 확정 정보(날짜, 담당자, 미정 항목)를 일관되게 유지했고, 신규 정보 및 조건 변경도 변경된 부분만 정확히 반영함. Turn 10의 "즉시 전체 재정리 대신 확인을 되물은" 행동은 오류라기보다 시스템 프롬프트의 "확인 질문 우선" 규칙이 반영된 보수적 동작으로 해석되며, 실무상 오히려 안전한 태도로 볼 수 있음.
